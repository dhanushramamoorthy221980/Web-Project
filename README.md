# Smart Classroom Attention Analyzer

A Computer Vision-based project designed to monitor and analyze student attention levels in a classroom environment. It utilizes face detection, gaze estimation, head pose tracking, and facial expression analysis to compute individual and collective attention metrics.

## Project Structure

Below is the directory structure for the project:

```text
SmartClassroomAttentionAnalyzer/
├── app.py                  # Main entry point for starting the application
├── requirements.txt        # Python package dependencies
├── README.md               # Project documentation and setup instructions
├── modules/                # Custom packages and modules for modular application logic
│   └── __init__.py         # Makes the modules directory an importable package
└── reports/                # Destination directory for generated attention reports and logs
    └── .gitkeep            # Ensures the directory is tracked by version control
```

---

## File Explanations

### 1. `app.py`
The central hub and main entry point of the project. It coordinates initialization of the camera feed/video inputs, coordinates inference pipelines using the modules, manages the user interface (if any), and oversees the export of analytics to the `reports` directory.

### 2. `requirements.txt`
Specifies all third-party Python packages required to run the project. Crucial libraries included:
*   `opencv-python`: Used for video capturing, image processing, and drawing UI overlays.
*   `numpy`: Used for high-performance numerical operations on image matrices.
*   `mediapipe`: Google's framework used for robust face mesh tracking, eye gaze estimation, and head pose estimation.
*   `ultralytics`: Provides YOLO models if student/object detection (e.g., cell phone usage, raised hands) is integrated.
*   `pandas` & `matplotlib`: Used for structuring and plotting student attention statistics over time.

### 3. `modules/`
This package directory will house all custom sub-modules to keep the codebase clean and modular. Potential future files to add:
*   `detector.py`: Handlers for face and head detection.
*   `gaze.py`: Logic to track eye look vectors and determine focus zones.
*   `metrics.py`: Calculation algorithms for compute attention scoring.
*   `reporter.py`: Handles file formats and writing logic for reports.

### 4. `reports/`
Holds execution data, logs, CSV files, and visual graphs generated by the system. Examples include lesson attention summaries, individual student logs, or attention heatmaps.

## Setup Instructions

### Prerequisites
*   **Python 3.11** (Ensure this is installed and configured on your system)

### Virtual Environment Setup
1. Open your terminal in the project root directory.
2. Activate your existing virtual environment (`venv`):
   *   **Windows (PowerShell):**
       ```powershell
       .\venv\Scripts\Activate.ps1
       ```
   *   **Windows (Command Prompt):**
       ```cmd
       .\venv\Scripts\activate.bat
       ```
   *   **Linux / macOS:**
       ```bash
       source venv/bin/activate
       ```
3. Install dependencies:
   ```bash
   pip install --upgrade pip
   pip install -r requirements.txt
   ```
